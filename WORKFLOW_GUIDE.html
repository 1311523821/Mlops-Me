MLOps 工作流 — 完整使用指南

一套轻量级、单 GPU 的深度学习项目管理工具。
核心目标：快速验证想法 + 训练记录自动归档。

1. 核心概念

train.py
训练模型
→
evaluate.py
评估 + 画图
→
export.py
导出 ONNX
→
deploy/app.py
推理服务

每一步自动写入 mlflow.db，通过 mlflow ui 在浏览器查看所有训练记录。

文件/目录你需不需要改说明
core/不改框架基础设施（trainer、registry、utils），通用代码
tasks/要改你的任务代码（模型 + 数据集），这是你主要写代码的地方
config.yaml要改项目名、路径、超参数
train.py不改入口脚本，通用编排器
evaluate.py不改评估脚本，通用
export.py不改ONNX 导出，通用
deploy/可能改如需自定义预处理/后处理，改 app.py
mlflow.db不改MLflow 自动管理，你只看浏览器里的 UI
mlruns/不看MLflow 内部用的临时目录，无视它

2. 新建一个自己的项目

假设你要做一个红外小目标检测项目，只需要 3 步。

第 1 步：创建任务目录

cp -r tasks/demo tasks/ir_detection

把 demo 复制一份，改名为你的项目名。目录结构：

tasks/ir_detection/
├── __init__.py          # 空文件，标记这是一个 Python 包
├── model.py             # 在这里写你的模型
└── dataset.py           # 在这里写你的数据加载逻辑

第 2 步：写你的模型（model.py）

把 demo 的例子替换成你自己的模型：

from core.base_model import BaseModel
from core.registry import register_model

@register_model("ir_resnet")  # ← 给模型起个名字
class IRDetectionModel(BaseModel):
    def __init__(self, num_classes=2):
        super().__init__()
        # ===== 你的模型结构写在这里 =====
        self.backbone = ...
        self.head = ...
        # ================================

    def forward(self, x):
        return self.head(self.backbone(x))

    def get_example_input(self):
        import torch
        return torch.randn(1, 3, 256, 256)  # ← 改成你的输入尺寸

    @classmethod
    def from_config(cls, config):
        # 从 config 里读参数，构建模型
        return cls(num_classes=config.get("_num_classes", 2))
关键：@register_model("ir_resnet") 装饰器把模型注册到全局注册表，之后 train.py 就能通过名字找到它。

第 3 步：写你的数据加载（dataset.py）

from core.base_dataset import BaseDataset
from core.registry import register_dataset

@register_dataset("ir_dataset")  # ← 给数据集起个名字
class IRDataset(BaseDataset):
    CLASS_NAMES = ["背景", "目标"]

    def __init__(self, data_dir, train=True, data_fraction=1.0):
        # ===== 加载你的数据 =====
        self.samples = load_your_data(data_dir, train)
        if data_fraction < 1.0:
            n = int(len(self.samples) * data_fraction)
            self.samples = self.samples[:n]
        self.transform = get_your_transforms(train)

    @property
    def num_classes(self):
        return 2  # ← 你的类别数

    def __len__(self): return len(self.samples)
    def __getitem__(self, idx):
        img, label = self.samples[idx]
        return self.transform(img), label

    @classmethod
    def from_config(cls, config, split):
        return cls(
            data_dir=config["paths"]["data_dir"],
            train=(split == "train"),
            data_fraction=config.get("_data_fraction", 1.0),
        )

3. 修改配置文件

打开 config.yaml，改这几处：

# 项目元信息
project:
  name: "ir-detection"            # 改成你的项目名
  tags:
    framework: "pytorch"
    owner: "your-name"

# 全量训练用这个模型
full:
  model_name: "ir_resnet"           # 和 @register_model 的名字一致
  epochs: 100
  batch_size: 32

# 快速验证用这个
fast:
  model_name: "ir_resnet"
  epochs: 3
  batch_size: 16
  data_fraction: 0.1

Step 1：快速验证（2 分钟）

python train.py --task ir_detection --fast

用 10% 数据、3 epoch 快速跑通，确认没有 bug。

Step 2：查看 MLflow 记录

# 启动 MLflow UI（如果还没启动）
mlflow server --backend-store-uri sqlite:///mlflow.db --port 5000

# 浏览器打开
http://127.0.0.1:5000

在 UI 里你能看到：

  • 实验列表（左侧）→ 选 ir-detection
  • 训练曲线：val_accuracy ↑、train_loss ↓
  • 参数：learning_rate、batch_size、model_name ...
  • 标签：data_fingerprint、framework、task ...
  • 模型文件：best_model.pth（可下载）

Step 3：全量训练

python train.py --task ir_detection

用全部数据、完整 epoch 训练。自动记录到同一个实验下，方便对比。

Step 4：评估

python evaluate.py --task ir_detection

生成：

  • 测试集准确率 + 分类报告（precision / recall / f1）
  • outputs/ir_detection/comparison.png — 当前 vs 历史最佳对比图
  • outputs/ir_detection/confusion_matrix.png — 混淆矩阵

Step 5：导出 ONNX

python export.py --task ir_detection

输出 outputs/ir_detection/model.onnx，打印 PyTorch vs ONNX 的精度差异。

Step 6：部署推理服务

python deploy/app.py --model outputs/ir_detection/model.onnx
端点说明
GET /health健康检查 → {"status":"ok"}
POST /predict上传图片文件推理 → curl -X POST -F "file=@test.png" ...
GET /predict?url=xxx通过图片 URL 推理

→

→

出最终模型

核心哲学：--fast 是你的快速实验开关。每次改完模型，先 --fast 跑 2 分钟验证没有崩溃，再 mlflow ui 看曲线，确认效果变好了才全量训练。不浪费时间在烂 idea 上。

6. 数据指纹是什么？

每次训练前，系统自动对数据集前 100 个样本计算 MD5 哈希，记录在 MLflow 标签里。

  • 数据不变 → 指纹相同：可以对比不同超参数在同一份数据上的效果
  • 数据变了 → 指纹不同：如果某次训练效果异常，先查指纹是不是换了数据

这是 MLOps 的数据版本管理最简实现——不需要 DVC 之类重工具，一行哈希就够个人用了。

7. 常见问题

Q: mlruns/ 下面没有 meta.yaml，是不是坏了？
A: 不是。用了 SQLite 后实验信息存在 mlflow.db 里，mlruns/ 只是放模型文件的筐。一切看 http://127.0.0.1:5000 就行。
Q: 怎么对比两次训练的曲线？
A: MLflow UI 里按住 Ctrl 点选两次 run，右侧自动叠图对比所有指标。
Q: deploy/app.py 预处理和训练时不一样怎么办？
A: app.py 里的 TRANSFORM 变量需要和 dataset.py 里的 transform 保持一致（均值、标准差、缩放尺寸）。目前硬编码在 app.py 中，复杂场景需要各自维护。
Q: 我要同时管理红外和声纳两个项目？
A: 改 config.yaml 里的 project.name 即可。每次训练时会以这个名字创建/使用 MLflow 实验。或者在命令行传入不同 config： 
python train.py --task ir_detection --config config_ir.yaml
python train.py --task sonar_3d    --config config_sonar.yaml
