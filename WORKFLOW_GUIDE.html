MLOps 工作流 — 完整使用指南

一套轻量级、单 GPU 的深度学习项目管理工具。
核心目标：快速验证想法 + 训练记录自动归档 + 分类/分割双任务支持。

1. 核心概念

train.py
训练（--fast / --resume）
→
evaluate.py
评估 + 画图
→
export.py
ONNX + preprocess.json
→
deploy/app.py
FastAPI 推理服务

每一步自动写入 mlflow.db，通过 mlflow server 在浏览器查看训练曲线和对比图。

文件/目录你需不需要改说明
core/不改框架基础设施（trainer、registry、utils）
tasks/要改你的任务代码（模型 + 数据集），这是你主要写代码的地方
config.yaml小改全局公共项（路径、设备），几乎不动
tasks/xxx/config.yaml要改任务级配置：模型、数据集、消融参数
train.py不改入口脚本，自动合并全局+任务配置
evaluate.py不改评估脚本，自动适配分类/分割
export.py不改ONNX 导出，自动附带 preprocess.json
deploy/不改自动读取 preprocess.json，无需手工调 transform
mlflow.db不改MLflow 自动管理，你只看浏览器里的 UI

2. 任务类型

框架支持两种任务类型，由模型的 task_type 属性声明：

task_type任务默认 Loss评估指标示例
classification图像分类CrossEntropyLossaccuracy ↑demo, image_classification
segmentation目标检测/分割自定义（如 DiceFocalLoss）IoU ↑sonar_detection
Trainer 不硬编码任何任务：loss 函数、评估指标都由模型自己声明。加新任务类型只需在 model.py 里设 task_type 和 get_loss_fn()。

3. 配置层级

配置文件分两级，全局和任务各自维护：

config.yaml                   ← 全局公共项（路径、设备、MLflow）
tasks/demo/config.yaml         ← demo 的 fast/full 默认值
tasks/sonar_detection/config.yaml  ← LVNet 消融参数

合并规则：任务级配置覆盖全局配置的同名字段。train.py 自动合并，你不需要手动处理。

全局 config.yaml（尽量不动）

project:
  name: "mlops-workflow"
paths:
  data_dir: "./data"
  output_dir: "./outputs"
  mlflow_uri: "sqlite:///mlflow.db"
device:
  gpu_id: 0
  use_cuda: true
training:
  learning_rate: 0.001
  optimizer: "adam"

任务 config.yaml（经常改）

# tasks/sonar_detection/config.yaml

fast:
  model_name: "lvnet_tiny"
  dataset_name: "sonar_e2e"
  batch_size: 1         # LVNet 显存大

full:
  epochs: 50

# 消融实验参数
model_params:
  encoder_type: "stsf"   # cnn | stsf — 改这里做消融
  mlp_type: "conv3d"     # mlp | conv3d
  block_type: "decoupled" # swin | decoupled

segmentation:            # 分割任务参数
  num_frame: 4
  img_size: 512
消融实验工作流：改 tasks/xxx/config.yaml 的一个参数 → python train.py --task xxx --fast → MLflow UI 对比曲线。每次改一个变量，MLflow 自动记录全部参数，消融结论一目了然。

4. 新建一个分类项目

第 1 步：复制模板

cp -r tasks/demo tasks/my_project

第 2 步：写模型（model.py）

from core.base_model import BaseModel
from core.registry import register_model

@register_model("my_model")
class MyModel(BaseModel):
    task_type = "classification"  # ← 声明任务类型

    def __init__(self, num_classes=10):
        super().__init__()
        self.backbone = ...
        self.head = nn.Linear(512, num_classes)

    def forward(self, x):
        return self.head(self.backbone(x))

    def get_example_input(self):
        return torch.randn(1, 3, 224, 224)

    @classmethod
    def from_config(cls, config):
        return cls(num_classes=config.get("_num_classes", 10))

第 3 步：写数据集（dataset.py）

from core.base_dataset import BaseDataset
from core.registry import register_dataset

@register_dataset("my_dataset")
class MyDataset(BaseDataset):
    CLASS_NAMES = ["cat", "dog", ...]

    def __init__(self, data_dir, train=True, data_fraction=1.0):
        ...

    @property
    def num_classes(self): return len(self.CLASS_NAMES)
    def __len__(self): return len(self.samples)
    def __getitem__(self, idx): return img, label

    def get_preprocess_config(self):
        """返回推理预处理参数，export.py 会保存到 preprocess.json"""
        return {"mean": [0.485,0.456,0.406], "std": [0.229,0.224,0.225],
                "size": [224,224], "channels": 3, "classes": self.CLASS_NAMES}

    @classmethod
    def from_config(cls, config, split):
        return cls(data_dir=config["paths"]["data_dir"],
                   train=(split=="train"),
                   data_fraction=config.get("_data_fraction", 1.0))

第 4 步：声明默认值（__init__.py）

DEFAULT_DATASET = "my_dataset"
DEFAULT_MODEL = "my_model"

5. 新建一个分割项目（声纳/红外检测）

分割任务和分类任务的区别只有 3 处：

① task_type 改为 "segmentation"

class MySegModel(BaseModel):
    task_type = "segmentation"  # ← 告诉 Trainer 用分割指标

    def get_loss_fn(self):
        return DiceFocalLoss()  # ← 自定义 loss

② 数据集返回 (frames, mask) 而非 (img, label)

def __getitem__(self, idx):
    frames = ...   # 多帧图片 (C, D, H, W) 或 (C, H, W)
    mask = ...     # 二值掩码 (1, H, W)
    return frames, mask

③ config.yaml 配置分割参数

segmentation:
  num_frame: 4            # 输入帧数
  img_size: 512           # 图像尺寸
  train_split: "train1.txt"
  val_split: "val_new.txt"
多帧输入由数据集处理，Trainer 不感知。LVNet 的输入是 (B, 1, 4, 512, 512)，4 帧灰度图堆叠。完全由 dataset.__getitem__ 控制。

7. 完整工作流

Step 1：快速验证

python train.py --task my_project --fast

用 10% 数据、3 epoch 快速跑通。

计算数据指纹...
数据指纹 (MD5): a1b2c3d4...                 ← 数据集版本标记
============================================================
任务: my_project  |  模型: my_model  |  类型: classification
设备: cuda:0  |  模式: 快速模式
Epoch   1/3 | train_loss: 0.xx | val_loss: 0.xx | val_accuracy: 0.xx

Step 2：查看 MLflow

mlflow server --backend-store-uri sqlite:///mlflow.db --port 5000
# 浏览器打开 http://127.0.0.1:5000

左侧实验列表看到你的项目，点击 run 查看 train_loss ↓ / val_loss ↓ / val_accuracy ↑ 三条曲线。

Step 3：全量训练 + 断点续训

python train.py --task my_project                         # 全量
python train.py --task my_project --resume                # 断点续训

Step 4：评估

python evaluate.py --task my_project

分类任务：accuracy + 分类报告 + 混淆矩阵
分割任务：IoU + 历史最佳对比

Step 5：导出 ONNX

python export.py --task my_project

输出：

  • outputs/my_project/model.onnx — ONNX 模型
  • outputs/my_project/preprocess.json — 推理预处理参数（自动生成）

preprocess.json 是解耦关键：deploy/app.py 启动时自动读取，不需任何任务特定代码。

Step 6：部署推理服务

python deploy/app.py --model outputs/my_project/model.onnx
端点说明
GET /health健康检查
POST /predict上传文件推理
GET /predict?url=xxxURL 推理
preprocess.json 把预处理和模型绑定，无需改 app.py 代码就能适配任何任务。

8. 数据指纹

每次训练前，系统对数据集前 100 个样本计算 MD5 哈希，记录在 MLflow 标签里。

  • 数据不变 → 指纹相同：对比不同超参在同一份数据上的效果
  • 数据变了 → 指纹不同：训练效果异常时先查指纹

9. 常见问题

Q: mlruns/ 下面没有 meta.yaml？
SQLite 后端把实验信息存在 mlflow.db，mlruns/ 只是模型产物临时目录。一切在浏览器 UI 里看。
Q: 怎么对比两次训练？
MLflow UI 里 Ctrl 点选两条 run，右侧自动叠图。
Q: 分类和分割怎么切换？
改模型里的 task_type + get_loss_fn()，Trainer 自动适配。不用改任何 core/ 代码。
Q: 多个项目怎么管理？
改 config.yaml 的 project.name，或用不同配置文件： 
python train.py --task ir --config config_ir.yaml
python train.py --task sonar --config config_sonar.yaml
Q: 训练中断了怎么办？
python train.py --task xxx --resume
从 best_model.pth 恢复模型权重、optimizer 状态、epoch 计数。
